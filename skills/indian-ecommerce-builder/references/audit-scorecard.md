# Audit scorecard

Score each line 0 (missing) / 1 (partial) / 2 (done). Check on a 375px phone first. Record evidence (quote
or screenshot) for every score. Fix order = (impact H/M/L) × (effort S/M/L), high impact + small effort first.

## 1. First 5 seconds (homepage, mobile)
- [ ] Announcement bar: one offer or promise, ≤ 60 chars, rotates max 3 messages (H/S)
- [ ] Hero says what is sold + for which occasion, with one CTA, image ≤ 200 KB, no text baked into image (H/S)
- [ ] Current festival visible above the fold during its window, with real date/countdown (H/S)
- [ ] Trust strip: COD, delivery days, returns, secure (H/S)
- [ ] Category tiles (circles or cards) with real product photos (H/S)

## 2. Merchandising
- [ ] Every active product in at least one category collection; no empty or 1-product collections in nav (H/S)
- [ ] Shop by occasion, colour, price, and size (M/M)
- [ ] Bestsellers rail shows products that are actually in stock and are the core range (H/S)
- [ ] New arrivals + gift edit (M/S)
- [ ] Collection filters: colour, size, price, availability; sort by bestselling default (M/S)

## 3. Product cards
- [ ] Second image on hover (desktop) (M/S)
- [ ] MRP strikethrough + "% OFF" badge when compare-at > price (H/S)
- [ ] Price as ₹599 (no decimals) (L/S)
- [ ] Colour count / swatches ("13 colours") (M/S)
- [ ] Rating stars when reviews exist (H/M)
- [ ] Quick add or clear tap target on mobile (M/S)

## 4. Product page
- [ ] 5+ images incl. on-wrist and scale shots; zoom; variant photos switch with colour (H/M)
- [ ] Size guide with inner diameter + measuring method, opens in place (H/S)
- [ ] COD + delivery days + returns line directly under buy buttons (H/S)
- [ ] Sticky add-to-cart on mobile (M/S)
- [ ] Offer reminder (welcome code / festival code) near price (M/S)
- [ ] Reviews with photos (H/M) — app
- [ ] Cross-sell "Complete the stack" (M/S)

## 5. Offers & retention
- [ ] Welcome offer (10%) captured by popup → email/WhatsApp; code works for brand-new guests (H/S)
- [ ] Festival discount live with start/end dates matching the festival (H/S)
- [ ] Free-shipping threshold + cart progress bar (M/M)
- [ ] Abandoned cart via WhatsApp/email (H/M) — app
- [ ] Prepaid nudge (small % off prepaid) if COD RTO is high (M/M)

## 6. Social proof & community
- [ ] Instagram feed or reels row, with fallback content (M/M)
- [ ] Customer photos / testimonials with first name + city (H/M)
- [ ] WhatsApp chat button, prefilled message per product (M/S)

## 7. Trust & compliance (India)
- [ ] Policies published: refund, shipping, privacy, terms; grievance officer named (H/S)
- [ ] Seller name, address, country of origin, MRP incl. taxes (Legal Metrology) (M/S)
- [ ] Contact page with phone/WhatsApp/email; GST no. in footer (M/S)
- [ ] No dark patterns: real timers, real stock, real reviews (H/S)

## 8. Speed & SEO
- [ ] Mobile PageSpeed ≥ 60, LCP < 2.5 s (H/M)
- [ ] Titles/meta use Indian search terms; product JSON-LD; alt text with colour + type (M/S)
- [ ] No test/draft products visible; no broken links; 404 is helpful (L/S)

## 9. Taste
- [ ] One accent colour, consistent type scale, generous spacing, photography consistent in light/background
- [ ] Motion is subtle (≤ 400 ms, no bounce), honours reduced motion
- [ ] Nothing looks like a template default (placeholder text, stock icons, "Disclosures" headings)
